# 樂法 Le Phare 飲料店

樂法斗六店的配方練習遊戲。櫃台客人點單，照配方表把飲料做出來，做得準不準、快不快決定客人滿意度。

線上玩：https://yui02287.github.io/PHARE/

電腦與手機都能玩。手機請直拿：整個畫面固定不用捲，上面看訂單、容器和紙杯，下面用「素材｜冰塊・設備｜杯內・收尾」三個分頁切換工具；點液體會自動跳出量杯，倒完自動收起；最底一列是配方表、撤銷、送出。

## 怎麼玩

開始時先選要練習的系列（可多選，或直接選「全部系列」），每輪 10 杯；選擇會記住，下次打開直接帶入。一輪結束後可以「再練一輪」或「換練習種類」。

1. 點櫃台的客人接單，訂單上會寫杯型、冰量與甜度。
2. 選容器：紙杯、雪克杯、果汁機、萃茶機。每杯一開始選的是紙杯，要搖茶或加熱時再切到雪克杯。
3. 加料：液體用量杯（點液體就裝上量杯，按住「裝填」到正確毫升再按「倒入」）；糖醬點一下選重量；勺料點一下加一勺。
4. 做動作：搖茶、蒸汽機加熱、果汁機、攪拌、榨蘋果、萃茶鍵 3／5。
5. 把雪克杯、果汁機、萃茶機的東西倒進紙杯，選收尾（補水／補茶／不補），送出。

看不懂配方時按「配方表」，點開每一杯可以看到用量與這杯適用的速記規則，打開時遊戲會暫停。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 遊戲本體（介面、邏輯、計分） |
| `recipes.js` | 108 款配方資料 |
| `audio.js` | 音樂與音效（瀏覽器即時合成，沒有音檔） |
| `tests/` | 驗收腳本：遊戲 32 條、音訊 20 條、手機 10 條 |
| `BRAND.md` | 樂法品牌色與字型規範 |
| `PLAN*.md` | 各版設計規格 |

## 本機執行

任何靜態伺服器都可以，例如：

```bash
npx serve . --listen 8765
```

再開 http://localhost:8765 。

## 資料來源

配方來自「樂法斗六店 配方表」，糖一律為蔗糖（店員確認）。2026-09 新品（葡萄多多、西瓜三款新甜度）依店內新品規格更新。
